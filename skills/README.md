# Web Design Director Skill

A reusable skill definition for designing and implementing distinctive websites while avoiding generic AI-generated styling.

## Files

- `SKILL.md` — main skill instructions
- `references/design-intake.md` — questions used when the requested direction is unclear
- `references/quality-checklist.md` — final review checklist

## Suggested use

Place the folder in a skill-capable environment, or copy the contents of `SKILL.md` into project instructions/custom instructions.

Example request:

> このスキルを使って、自作ゲームをまとめるポータルサイトを作ってください。レトロゲーム雑誌風で、HTML/CSS一式を納品してください。

When no direction is supplied, the skill begins with:

> 希望するデザイン形態を指示してください。
