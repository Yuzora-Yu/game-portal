# Design Intake

Use this only when the request does not already specify a design direction.

## First question

希望するデザイン形態を指示してください。

Suggested choices:

- レトロ印刷物・ゲーム雑誌風
- ミニマル・余白重視
- ブルータリズム・実験的
- 企業・公共施設向け
- 参考URLや画像に寄せる
- おまかせ

## Optional follow-up questions

Ask only what is materially missing.

1. このサイトで最優先の行動は何ですか。
2. 必要なページや項目を教えてください。
3. 使用してよい画像やロゴはありますか。
4. 参考デザインのどこを取り入れますか。
5. HTML一式とデザイン案のどちらが必要ですか。

Do not turn the intake into a long questionnaire.
