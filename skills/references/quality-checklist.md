# Web Design Quality Checklist

## Concept
- One-sentence art direction exists.
- The visual decisions support the site's content.
- The site does not look like a generic component library demo.

## Content
- Headings describe the actual content.
- Primary action is clear.
- Placeholder text is visibly marked.
- Legal and advertising claims are not invented.

## Visual system
- Palette is limited and consistent.
- Typography roles are clear.
- Spacing follows a repeatable rhythm.
- Borders, radii, shadows, and effects have a reason.
- Real project assets are used where available.

## Navigation
- Logo/home link goes to the intended page.
- Header links point to valid pages or IDs.
- Fixed headers do not cover anchors.
- Current-page and hover/focus states are understandable.

## Responsive
- No horizontal overflow at 320px.
- Touch targets are usable.
- Long Japanese text wraps cleanly.
- Images retain useful crops.
- Desktop hierarchy survives mobile stacking.

## Accessibility
- Semantic landmarks are present.
- Skip link works.
- Keyboard focus is visible.
- Image alt text is appropriate.
- Contrast is readable.
- Reduced-motion preference is respected.

## Deployment
- Relative paths match the chosen host.
- Local preview instructions use an HTTP server.
- GitHub Pages and Cloudflare Pages base paths are considered.
- Asset filenames and letter case match exactly.
- Ad and analytics placeholders are documented.
